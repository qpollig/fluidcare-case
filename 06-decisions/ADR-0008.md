# ADR-0008. Воспроизводимая сборка, защищённая конфигурация и демо-редакция

**Статус:** принято

## Контекст

Программу ставят на рабочие ПК без Python. Пароль к БД нельзя хранить открытым текстом. Нужна версия для показа без доступа к реальным данным.

## Решение

Сборка из зафиксированных зависимостей с хешами, тесты внутри сборки и установщик с контрольной суммой. Пароль шифруется средствами ОС на уровне машины. Демо-редакция задаётся только при сборке: своя локальная БД, без драйвера рабочей БД.

## Рассмотренные альтернативы

- Ручная установка Python на каждый ПК
- Пароль в открытом конфиге
- Демо-режим флагом в настройках

## Последствия

**Плюсы**

- Ровно один артефакт на версию
- Демо невозможно переключить на реальные данные

**Цена**

- Привязка к Windows
- Две конфигурации сборки
