# ADR-0007. Переход на PySide6 по утверждённому дизайну

**Статус:** принято

## Контекст

Прототип на tkinter состоял из отдельных окон с проблемами обновления состояния, плохо масштабировался и выглядел устаревшим.

## Решение

Сначала спецификация дизайна, токены, светлая и тёмная тема и макеты, затем реализация на PySide6 (Qt) в одном окне с боковой панелью редактора.

## Рассмотренные альтернативы

- Доработать tkinter
- Веб-клиент

## Последствия

**Плюсы**

- Современный интерфейс, единое окно, график накопительного баланса
- Интерфейс покрыт автотестами

**Цена**

- Заметный рост объёма кода
- Особенности Qt, которые нужно учитывать в тестах
