# ADR-0003. Общий PostgreSQL в сети больницы

**Статус:** принято

## Контекст

Врачи работают с нескольких ПК, данные пациента должны быть одинаковыми на всех рабочих местах.

## Решение

Единственное рабочее хранилище — PostgreSQL на сервере в локальной сети больницы. Локальная SQLite допускается только для разработки и демо-версии и никогда не включается молча.

## Рассмотренные альтернативы

- Локальная БД на каждом ПК
- Файл на общем сетевом диске

## Последствия

**Плюсы**

- Все врачи видят одни и те же данные
- Централизованный бэкап и администрирование

**Цена**

- Нужна связь с сервером: добавлен индикатор связи
- Параллельные правки: см. ADR-0004
